# Contribution Guidelines

Thanks for helping to improve this list. Please check the following before opening a pull request:

- The entry is about Amazon ECS or AWS Fargate, or is clearly useful for people running workloads on them.
- The project is maintained: it had a commit or release in the last 12 months and is not archived or deprecated.
- You use it or would recommend it. This list favors the best options over a complete one.
- Add one entry per pull request, at the bottom of the matching section, unless the section is sorted alphabetically.
- Use the format `- [Name](link) - Description.` The description starts with a capital letter, ends with a period and says what the entry does, not how great it is.
- Mark commercial products with `Commercial.` at the end of the description.
- Link to the project's repository or main page, not to a blog post about it.
- Check your spelling and run `npx awesome-lint` before you submit.

Entries that stop being maintained are removed during regular reviews.
